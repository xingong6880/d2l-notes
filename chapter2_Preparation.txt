包非常重要----------------------------------------------------------------------------------------------C1：simple functionimport torchx = torch.arange(4.0)x.requires_grad_(True)		# 原地设置张量记录梯度，后续对 x 的依赖操作会被 Autograd 记录print(x.grad)  				# 输出: None	# 在调用 backward 之前，梯度属性为 None（尚未计算）y = 2 * torch.dot(x, x)print(y)       				# 输出: tensor(28., grad_fn=<MulBackward0>) # grad_fn 表示 y 是由乘法操作产生的中间张量y.backward()				# 对标量 y 调用反向传播，Autograd 计算 dy/dx 并把结果存入 x.gradprint(x.grad)  				# 输出: tensor([ 0., 4., 8.,12.])	# 打印 x 的梯度：dy/dx = 4 * x，因此期望 [0., 4., 8., 12.]print(x.grad == 4 * x) 		# 输出: tensor([True, True, True, True])	# 验证计算是否等于 4*x（逐元素比较）x.grad.zero_()  			# 此时 x.grad 变为 tensor([0.,0.,0.,0.])	# 清零梯度（原地操作），以便进行下一次独立的反向传播y = x.sum()				# 构造新的标量 y = sum(x) 并反向传播y.backward()print(x.grad) 				 # 输出: tensor([1.,1.,1.,1.])# 对于 y = sum(x)，dy/dx = 1，对每个分量都是 1----------------------------------------------------------------------------------------------C2:Backward for Non-Scalar Variables 非标量变量的反向传播在 PyTorch 中，只有标量（即 shape 为 () 的张量）可以直接调用 .backward()。如果你想对非标量张量（例如向量或矩阵）进行反向传播，必须先将其“归约”为标量，或者显式传入一个与其形状相同的 gradient 参数。x = torch.arange(4.0)x.requires_grad_(True)y = x * x# 构造一个非标量输出print(y)  # 输出: tensor([0., 1., 4., 9.], grad_fn=<MulBackward0>)# 不能直接调用 y.backward()，因为 y 不是标量# 所以我们传入一个与 y 相同形状的梯度张量y.backward(torch.ones_like(x))  # 相当于对每个分量求导并加权求和print(x.grad)  # 输出: tensor([0., 2., 4., 6.])，因为 dy/dx = 2x----------------------------------------------------------------------------------------------C3：Detaching Computation 分离计算#在 PyTorch 中，所有依赖于 requires_grad=True 的张量的操作都会被记录在计算图中，用于后续的反向传播。但有时我们希望中断梯度传播，或者从当前计算图中分离出一个张量，这时就需要使用 .detach()。x = torch.arange(4.0, requires_grad=True)x.grad.zero_()y = x * xu = y.detach()       # u 是常量，不参与梯度传播z = u * x            # z = x³，但 u 不追踪梯度z.sum().backward()print(x.grad)        # 输出: tensor([0., 1., 4., 9.]) == u#虽然 z = x * x * x 看起来像是三次方，但由于中间变量 u = y.detach()，梯度传播被截断，反向传播只计算 dz/dx = u，而不是 3 * x * x。x.grad.zero_()       # 清空梯度y.sum().backward()   # 对 y 进行反向传播print(x.grad == 2 * x)  # 输出: tensor([True, True, True, True])   #虽然 y 的副本 u 被 .detach() 了，但 y 本身的计算图还在。所以我们可以继续对 y 做 .backward()，并得到正确的梯度 dy/dx = 2 * x----------------------------------------------------------------------------------------------C4：Gradients and Python Control FlowPyTorch 的自动微分机制支持包含 Python 控制流（如 if、while、函数调用等）的计算图。即使这些控制流在运行前是未知的，PyTorch 仍能正确追踪依赖关系并计算梯度。def f(a):    b = a * 2    while b.norm() < 1000:        b = b * 2    if b.sum() > 0:        c = b    else:        c = 100 * b    return ca = torch.randn(size=(2,), requires_grad=True)d = f(a)d.backward()print(a.grad)print(a.grad == d / a)  # 输出: tensor(True)----------------------------------------------------------------------------------------------C5:Conclusion	自动微分（automatic 定义：所有可能结果的集合   - 例子：     * 抛一次硬币：S = {正面, 反面}     * 掷一次骰子：S = {1,2,3,4,5,6}     * 抛两次硬币：S = {(正,正), (正,反), (反,正), (反,反)}2. 事件 (Event)   - 定义：样本空间的一个子集   - 例子：     * A = “第一次抛硬币是正面” = {(正,正), (正,反)}     * B = “骰子掷出奇数” = {1,3,5}   - 当实验结果 ∈ A 时，事件 A 发生3. 概率函数 (Probability function)   - 定义：P : A ⊆ S → [0,1]   - 公理 (Kolmogorov, 1933)：     * P(S) = 1     * P(A) ≥ 0     * 若 A_i 两两互斥，则 P(∪ A_i) = Σ P(A_i)----------------------------------------------------------------------------------------------C3：Random Variables（随机变量）1. 定义   - 随机变量是一个映射：把样本空间中的结果映射到数值集合。   - 例子：抛硬币     * 样本空间 S = {正, 反}     * 定义随机变量 X：       - X = 1 表示正面       - X = 0 表示反面2. 与样本空间的区别   - 样本空间：所有可能结果的集合。   - 随机变量：对这些结果的数值化描述，可以更粗略。   - 例子：样本空间是 [0,1] 上的所有点，     * 定义 Y = 1 当结果 > 0.5     * 定义 Y = 0 当结果 ≤ 0.53. 多个随机变量共享同一样本空间   - 例子：     * X：是否家里被盗 (0/1)     * Y：警报是否响起 (0/1)   - 它们基于同一个“世界状态”的样本空间。   - 知道一个随机变量的值，可能影响对另一个的判断（体现相关性）。4. 小结   - 随机变量是把“结果”转化为“数值”的工具。   - 它比样本空间更抽象、更灵活。   - 多个随机变量可以基于同一个样本空间，并可能存在依赖关系。----------------------------------------------------------------------------------------------C4：Multiple Random Variables1. 多个随机变量   - 随机变量可以同时存在，用来描述同一实验的不同方面。   - 例子：     * X = 病人是否有某种症状     * Y = 病人是否患某种疾病   - 多个随机变量之间可能存在相关性。2. 联合概率 (Joint Probability)   - 定义：P(A = a, B = b)，表示 A 取值 a 且 B 取值 b 的概率。   - 性质：P(A = a, B = b) ≤ P(A = a)，且 ≤ P(B = b)。3. 条件概率 (Conditional Probability)   - 定义：P(B = b | A = a) = P(A = a, B = b) / P(A = a)   - 含义：在已知 A = a 的情况下，B = b 的概率。   - 本质：在样本空间中限制到 A = a 的子集，并重新归一化。4. 贝叶斯定理 (Bayes’ Theorem)   - 公式：P(A | B) = [P(B | A) * P(A)] / P(B)  #重中之重   - 含义：用观测到的证据 B 来更新对事件 A 的信念。   - 常用形式：P(A | B) ∝ P(B | A) * P(A)	(1) 先验 (Prior)   - 表示在看到数据之前，我们对某个假设 H 的主观信念。   - 记作 P(H)。	(2) 似然函数 (Likelihood)   - 表示在假设 H 成立的前提下，观测到证据 E 的可能性。   - 记作 P(E | H)。	(3) 后验 (Posterior)   - 表示在看到证据 E 之后，我们对假设 H 的更新信念。   - 由贝叶斯公式给出：     P(H | E) = [P(E | H) * P(H)] / P(E)	(4) 直观理解   - 先验 P(H)：我原本的信念   - 似然 P(E | H)：在假设成立时，证据出现的可能性   - 后验 P(H | E)：结合证据后更新的信念   - 这就是“用数据修正原有信念”的过程5. 边缘化 (Marginalization)   - 对联合分布求和/积分，得到单个变量的分布。   - 例子：P(A) = Σ_b P(A, B = b)6. 独立性与条件独立性   - 独立性：P(A, B) = P(A)P(B)，等价于 P(B | A) = P(B)   - 条件独立性：P(A, B | C) = P(A | C) P(B | C)   - 例子：     * 症状与疾病可能相关     * 但在已知某个潜在原因 C 时，A 和 B 可能条件独立7. 直观例子   - 骨折与住院、肺癌与住院：骨折解释了住院原因 → 降低肺癌导致住院的概率   - 小学生的鞋码与阅读水平：表面相关，但在条件化“年龄”后变得独立----------------------------------------------------------------------------------------------C5：example1. 背景   - 医生给病人做 HIV 检测。   - 测试并非完美：存在假阳性和假阴性。   - 我们关心的是：在检测结果为阳性的情况下，病人真正患病的概率。2. 第一次检测   - 测试特性：     * P(D1=1 | H=1) = 1.0 （有病一定检测阳性）     * P(D1=1 | H=0) = 0.01 （健康者有 1% 概率假阳性）   - 先验：P(H=1) = 0.0015   - 结果：     P(H=1 | D1=1) ≈ 0.1306 （约 13%）   - 启示：即使测试很准，但由于疾病罕见，阳性预测值仍然不高。3. 第二次检测   - 新测试特性：     * P(D2=1 | H=1) = 0.98     * P(D2=1 | H=0) = 0.03   - 如果第一次阳性后再做第二次检测，且结果仍为阳性：     - 通过贝叶斯公式结合两次结果，可以显著提高对 H=1 的置信度。4. 两次检测联合   - 假设两次检测条件独立：     P(H=1 | D1=1, D2=1) =       [P(D1=1 | H=1) * P(D2=1 | H=1) * P(H=1)] /       P(D1=1, D2=1)   - 结果：P(H=1 | 两次阳性) ≈ 0.83 （约 83%）   - 启示：多次检测能显著提高诊断的可靠性。5. 小结   - 单次检测的阳性结果并不等于“几乎确定有病”，尤其在疾病低流行率时。   - 多次检测、结合不同测试的特性，可以大幅提升后验概率。   - 贝叶斯定理提供了一个系统方法：用先验 + 似然 → 更新为后验。----------------------------------------------------------------------------------------------C6: Expectations期望1. 期望 (Expectation)   - 定义：随机变量 X 的平均值     E[X] = Σ_x x * P(X=x)   （离散情况）     E[X] = ∫ x f(x) dx      （连续情况）   - 含义：加权平均结果，权重是概率。   - 应用：投资回报的平均收益、长期平均结果。2. 效用与期望效用 (Utility & Expected Utility)   - 人们决策时并非只看期望值，而是看“效用”。   - 效用函数 f(x)：描述结果带来的主观价值。   - 定义：E[f(X)] = Σ_x f(x) P(X=x)   - 特点：     * 效用函数常是非线性的（如对金钱的边际效用递减）。     * 风险厌恶：人们更倾向于稳定收益，而非高风险高回报。3. 方差 (Variance) 与标准差 (Standard Deviation)   - 方差定义：     Var[X] = E[(X - E[X])^2] = E[X^2] - (E[X])^2   - 标准差 = √Var[X]，与原变量单位一致，更直观。   - 含义：衡量结果的波动性或风险。   - 应用：投资风险评估。4. 协方差矩阵 (Covariance Matrix)   - 定义：     Σ = Cov[x] = E[(x - μ)(x - μ)^T]   - 性质：     * 对角线元素：各维度的方差     * 非对角元素：不同维度之间的协方差（相关性）   - 解释：     * v^T Σ v = Var[v^T x]，表示任意线性组合的方差     * 协方差为 0 → 两个变量不相关     * 协方差大 → 两个变量正相关5. 小结   - 期望：平均结果   - 效用：主观价值，解释风险偏好   - 方差/标准差：衡量不确定性大小   - 协方差矩阵：描述多维变量之间的相关性----------------------------------------------------------------------------------------------7.Documentation---Pytorch APIimport torchC1：Functions and Classes in a
